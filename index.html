QSP save converter

Converts a QSP .sav file between the classic 5.7.0 format (old desktop players) and the modern libqsp 5.9 format (qspider and players built on it), in whichever direction the save itself needs. Everything runs in this page — nothing is uploaded anywhere.

1. The save file

Drop a .sav here, or pick it.

2. The game file

The .qsp the save belongs to. It is needed to check that the save's location still exists in the game and to stamp the game's checksum. It is read, never changed.

Pick a save file to see which way it will be converted.
Open this page straight from disk or from any static host; it needs no server and makes no network requests. Extracted from the Girl Life Launcher project.
